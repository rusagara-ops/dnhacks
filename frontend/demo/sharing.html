Worker access

Each installation gets its own revocable worker credential. Get its installation ID with worker/.venv/bin/python worker/run.py --show-device-id, then paste that ID here. Newly enrolled workers start paused; review their settings before sharing.

Revoking a credential immediately blocks its next API request, including completion of an active task. Pause and let work finish before revoking when possible.
